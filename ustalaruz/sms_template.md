# SMS Shablonlar — Eskiz.uz uchun

## 1. Parolni tiklash (reset-request)

```
Usta ilovasi ning parolini tiklash uchun tasdiqlash kodi: 123456. Kod 15 daqiqa amal qiladi. Kodni hech kimga bermang!
```

---

## 2. Ro'yxatdan o'tish (register)

```
Usta ilovasi ga muvaffaqiyatli ro'yxatdan o'tdingiz. Xush kelibsiz!
```

---

## 3. Hamkorlik arizasi tasdiqlandi (application approved)

```
Usta ilovasi dan: Hamkorlik arizangiz tasdiqlandi! Endi siz ustalar safiga qo'shildingiz.
```
